# 实车原路返航方案

2026-11-17 · 设计稿，待实现和实车验证。

## 使用流程

车辆静止时在实时网页点「设为起点」，STM32 开始记录本次任务。用户正常遥控行驶，回程时点「原路返航」。车端停车并检查条件，原地转向约 180°，沿来时路线逐段返回，在起点附近减速停车，保持返程朝向。

网页显示记录、准备、掉头、返航、受阻、完成或中止，以及车端返回的原因。提供「停止返航」。手持端保留长按停车和手动接管。首版验证平整地面、短距离、以前进和转弯为主的路线。去程含明显倒车或横移时需要识别运动分段，首版应提示原因并拒绝启动。

## 数据与控制

| 部分 | 现状与实现方向 |
| --- | --- |
| 里程计 | [RouteLog.c](../project/Hardware/RouteLog.c) 已用四轮编码器增量计算平面位置和朝向。现有 1024 点补传缓存约每 80 ms 记录一次，最短约 82 秒覆盖旧点。沿用位姿计算和有效性检查，为任务独立保存起点和连续路径。 |
| 路线记录 | 保存有序位置、航向及有效状态。可从每移动 5–10 cm 或航向变化约 5°的采样阈值开始调试，保留转角及两端。返航前冻结去程。容量满、轨迹断段、主控重启或标定变更时提示原因，禁止跨断段返航。 |
| 掉头 | 以开始掉头时的航向加 180°为目标，限制角速度，接近目标时减速并确认停止。核对掉头后朝向与返程第一段是否相容。 |
| 路径跟踪 | 逆序跟踪路线段，候选目标限制在当前段附近；交叉路口按记录顺序推进。采用轻量前视控制，限制转角处的前视距离，抑制跨角切线。外环根据位姿误差给出车速及转向，内环根据编码器调节四轮转速。 |
| 轮速闭环 | [WheelSpeedConfig.h](../project/Hardware/WheelSpeedConfig.h) 默认仅监测。复用现有采样和故障检查，在返航模式独立启用并调试闭环，保留 PWM 上限、换向停顿与超时保护。 |
| 命令和状态 | 首版经网页、基座向 STM32 提交设起点、返航、停止命令。命令带任务 ID、请求序号和校验，重复请求不能再次掉头。按钮状态以 STM32 回执为准。继续保留路线 JSON 查看，返航目标取自本次车端记录。 |

网页显示去程、返程和当前目标段。STM32 负责路径计算和电机控制。首版采用持续在线的手持端监护，明确心跳和控制权，优先级为保护与停车、手动接管、自动返航。失联、主循环或串口异常、轮速或里程计异常、严重偏离或进度停滞时停车。连接恢复需要人为确认，不能自行重新起步。

## 测距和定位

返航时将云台朝行驶前方，根据实测制动距离、测距周期和余量设置减速和停车门槛。前方新增障碍时停车，等用户处理。要区分测距陈旧、设备故障和无有效回波，验证空旷地面及难检测目标。单个探头无法覆盖原地旋转的完整区域，首轮掉头测试选择已确认四周有足够净空的位置。首版实现遇障停车，后续绕行需要另外评估感知范围和规划。

编码器里程计会随打滑累积位置和航向误差。手持端的 MPU6050 测量遥控器姿态。先实测现有编码器的短程精度，再根据多弯测试决定是否考虑车载 IMU。实际能否回到起点需要现场量测。

## 实施与验收顺序

1. 架空核对轮序、正反向和每轮一圈计数，核对有效轮径、轮距、轴距，验证四轮低速闭环。
2. 平地测试原地 90°、180° 的实测角度、停止后的车体偏移和多次重复表现。
3. 联调设起点、命令确认、重复请求和状态回传，完成短直线去程与返程。用地面标记测终点偏差和返程最大横向偏差。
4. 逐步验证 L 形、多弯和交叉路径，确认按记录顺序回程。测试缓存满、主控复位和数据缺口时拒绝返航。
5. 验证障碍停车、手持接管、长按停车、断连停车和恢复后不自行起步。用诊断日志记录触发原因及停车响应。
6. 网页首版完成后再确定手持端入口。保留现有短按切模式、长按停车，考虑独立按键或 OLED 菜单。先核对手持芯片板型。

首版预计更新 STM32、基座 ESP 和实时网页。新增手持入口时再更新手持固件。
