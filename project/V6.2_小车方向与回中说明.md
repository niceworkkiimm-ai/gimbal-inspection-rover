# V6.2 小车方向与回中

> 这是 V6.2 的历史说明。当前版本为 V6.3，请先阅读同目录“V6.3_小车短暂异常恢复说明.md”；V6.3 需要更新 STM32 和手持 NodeMCU，不能照本页旧版的“仅烧录 STM32”操作。

更新日期：2026-09-07。只需重新编译并烧录STM32的Gimbal_STLink工程。

## 操作变化

- PWM上限由15%提高到30%。全倾约30度到达上限，PWM占空比与实测车速不等同。
- 保持与云台一致：Pitch控制前进/后退，Roll控制左转/右转。
- 根据“前后倾时云台上下动，但小车直走变转弯”的反馈，修正右侧2/4轮输出极性；1/3轮保持原极性。这是对镜像安装的修正，接线无需交换；实车前后/左右方向仍需试转确认。
- 停止死区和回中范围统一8度，避免已经停止却无法满足回中条件。
- 连续有效回中约0.4秒且至少10个不同的新包后自动恢复；一次失联、无效输入或过大倾斜后，仍需回中，不会带着倾斜突然重新启动。

零点沿用云台：ROLL为0度、PITCH为-2度。屏幕原始ROLL在-8~8度、PITCH在-10~6度时处于停止/回中范围。手持约30度已经满PWM，无需继续加大倾斜。

## 屏幕提示

| 提示 | 含义与恢复 |
| --- | --- |
| CAR:LEVEL | 等待回中，手持放平约半秒 |
| CAR:INPUT | 收到手持端的无效姿态标志；松开按钮并保持手持稳定，等有效数据恢复后回中 |
| CAR:TILT | 校正后任一轴超过55度；减小倾斜后回中 |
| CAR:LOST | 超过250ms没有新鲜小车输入；通信恢复后回中 |
| CAR:FAULT | 串口错误、主循环超时或异常保护；排查后退出小车模式再进入 |
| CAR:READY / RUN | 已就绪 / 正在输出PWM |

小车模式下ROLL/PITCH显示实时手持角度，不再显示固定的云台保持角；无效姿态显示横线。
CAR:INPUT无法单凭当前协议区分按键按下、MPU读取失败和加速度异常。若稳定放平后仍持续INPUT，需要继续检查手持端，不能据此宣称问题已经全部由STM32解决。
基座网页仍用原车辆状态码，INPUT/TILT会归入原有“请放平手持端”提示；详细原因看TFT。本次通信协议不变，两个ESP无需重烧。
