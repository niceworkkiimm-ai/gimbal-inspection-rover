# V8.12 三维模型统一与射线显示

本次仅更新网页：实时三维画面和扫描点回看共用 `gimbal-model.js`，均使用原版详细外壳与云台模型；实时画面去掉射线旁的半透明大三角形（`ConeGeometry`），保留细射线和测距点。

更新时请一并替换并刷新 `gimbal-3d-scan.html`、`gimbal-radar-standalone.html`、`scan-snapshot.js` 和新增的 `gimbal-model.js`，保留同目录的其他配套脚本。

路线快照仍使用 JSON `version: 2`，格式未变。已有快照直接用新版网页打开，三维回看就会采用详细模型，无需重新扫描或重新保存。

网页版本升为 **V8.12**；STM32 V8.10、基座 ESP V4.9、手持 V1.6、ESP32CAM_Camera V1.2 均保持原样，**所有设备无需重新烧录**。`User/main.c` 仅补充顶部版本注释，执行代码和 `FIRMWARE_VERSION "V8.10"` 不变。

完整接线、供电、轮向及控制协议均不变；基座通信仍为 UART4，PC10 TX、PC11 RX，115200/8N1。无需重新标定方向。

已完成本地验证：共享模型与原版的几何、材质和变换一致，实时与回看实例资源独立；7 组路线快照测试通过。浏览器以模拟遥测打开旧 V8.11 路线，详细模型、拖动旋转、关闭回看后的实时画面均正常，未见控制台错误。以上验证未连接实车。
