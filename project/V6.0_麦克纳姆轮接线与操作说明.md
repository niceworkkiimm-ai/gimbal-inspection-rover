## 工作方式

| 手持操作 | 结果 |
| --- | --- |
| 上电 | 默认云台模式，电机保持停止 |
| 短按并松开 D5 按键 | 云台 / 小车切换 |
| 切到小车 | 云台保持当时的指令角度；先放平约 0.4 秒，至少收到 10 个不同的新数据包 |
| 前倾 / 后倾 | 前进 / 后退，倾斜越大输出越大 |
| 左倾 / 右倾 | 左转 / 右转；没有前后倾时是原地转向 |
| 同时前倾和左倾 | 前进时左转 |
| 回到中间 | 电机 PWM 归零 |
| 切回云台或网页选择扫描 | 小车停车，再执行云台操作 |
| 按住按键 | 立即停止发送有效运动输入 |
| 长按约 0.8 秒 | 保持软件停车模式，松开不自动恢复；再短按回云台 |
| 断网、传感器数据无效 | 撤销驱动；恢复后必须重新满足回中条件。手持检测到断网会回云台模式 |
| 串口错误、主循环超时、急停触点断开 | 保护停车，排查后先退出小车模式再进入，并重新回中 |

标准麦克纳姆轮运动学取横移速度为 0，只使用前进量和旋转量：

`1号 = 3号 = 前进量 - 左转量`
`2号 = 4号 = 前进量 + 左转量`

“轮子前进方向”是轮子推动整车向前的方向，不等于四个电机都必须 DIR 高电平。

| 运动 | 1 左前 | 2 右前 | 3 左后 | 4 右后 |
| --- | --- | --- | --- | --- |
| 前进 | 前进 | 前进 | 前进 | 前进 |
| 后退 | 后退 | 后退 | 后退 | 后退 |
| 原地左转 | 后退 | 前进 | 后退 | 前进 |
| 原地右转 | 前进 | 后退 | 前进 | 后退 |

四轮应按标准麦克纳姆 X 型布局安装；实际轮型/滚子方向与电机极性要架空确认。本版不增加横移控制。

## 手持 NodeMCU V3 CH340G 接线

| 外设 | NodeMCU |
| --- | --- |
| MPU6050 VCC | 3V3 |
| MPU6050 GND | GND |
| MPU6050 SDA | D2，即 GPIO4 |
| MPU6050 SCL | D1，即 GPIO5 |
| MPU6050 AD0 | GND |
| MPU6050 INT / XDA / XCL | 不接 |
| 独立常开按键的一端 | D5，即 GPIO14 |
| 按键另一端 | GND |

D5 不是 GPIO5；不要用原来 ESP-01S 的 GPIO0 / GPIO2 接法。
若用四脚轻触按键，选两个按下才导通的触点；同一侧相通的两脚不能当作开关两端。
按键启用内部上拉，不需要再接 3.3V 或 5V。

用板载 USB 连接电脑烧录，也可用稳定 5V USB 电源供电。无需外接 USB-TTL，不要把 5V 接到 3V3。
上电时将手持端水平静止约 1 秒，等待陀螺仪校准；运动或读数失败会重试。

板载灯的含义：

- 云台：每秒短闪一下；
- 请求小车模式：正常通信时常亮；
- 软件停止：半秒闪烁；
- 网络或传感器未就绪：快闪。

灯只表示手持请求状态，不能证明车辆已经解锁。实际状态以 TFT 和基座网页为准。

## F407 到四路驱动板接线

适用于照片中的 **MD-TB6612 稳压版四路 PWM＋DIR 模块**。提供的旧 F103 示例使用裸板 AIN1/AIN2 接法，不能照抄。

| 轮号 / 位置 | 驱动板输入 | F407 引脚 | 硬件功能 |
| --- | --- | --- | --- |
| 1 / 左前 | M1PWM | PC6 | TIM8_CH1 |
| 1 / 左前 | M1DIR | PC4 | 普通输出 |
| 2 / 右前 | M2PWM | PC7 | TIM8_CH2 |
| 2 / 右前 | M2DIR | PC5 | 普通输出 |
| 3 / 左后 | M3PWM | PE5 | TIM9_CH1 |
| 3 / 左后 | M3DIR | PB12 | 普通输出 |
| 4 / 右后 | M4PWM | PE6 | TIM9_CH2 |
| 4 / 右后 | M4DIR | PB13 | 普通输出 |
| 共地 | GND | STM32 GND | 电池负极也共地 |
| 急停辅助常闭触点 | 独立低压触点两端 | PD3 与 GND | 闭合正常，断开停车 |

PWM 输出 20kHz。每路 PWM 在驱动板输入端接一个约 10kΩ 电阻到 GND，使 STM32 复位/未初始化时保持低电平。

PD3 仅作急停辅助反馈：内部上拉，正常时由常闭触点接 GND。急停的另一路合适额定值的触点/电路必须独立切断电机供电。不能把电池电压接到 PD3，也不能仅用短接 PD3 冒充已接好硬件急停。
板上的 ON/OFF 可以切电，但是否满足独立急停和辅助触点需求要实物确认。

PC6/PC7/PE5/PE6 也出现在板子的摄像头接口中；本项目没有使用摄像头，不能再把这些引脚接给另一外设。
没有使用 PE9/PE11/PE13/PE14，因为开发板手册显示它们连着板载 SRAM。

## 驱动板到电机 / 电源

- M1+/M1- 接左前电机两根动力线；M2 接右前，M3 接左后，M4 接右后。
- 根据电机真实引脚表识别动力线、编码器供电、A/B，不按照片线色猜测。
- 本版编码器 E1A/B～E4A/B 和 ADC 输出不接 STM32，不提供测速、四轮 PID 或里程计。
- 电池经过合适的保险和独立急停切断路径，再接驱动板 Vin+ / Vin-。电压必须同时符合模块标示的 6～13V 和电机额定值。
- 模块资料标称每路持续 1.2A；3.2A 峰值不能当作持续可用电流。必须检查电机堵转/启动电流、持续负载、散热与保险。
- 不要从 STM32 或 NodeMCU 的 3.3V 引脚给电机供电。
- 驱动板 5V/3V3 排针是电源输出，不能接 MCU 信号脚；不要将其与另一电源输出并联。
- 资料对 5V 输出电流有 3.5A/5A 等不同标注，不能未经确认就按 5A 给整机设计供电。
- 如以后连接编码器，模块 V 选择跳帽决定编码器供电，必须先核对编码器规格和输出电平；它不是电机 Vin 的选择开关。

## 软件与安全实现

- H1 包含序号、请求模式、切换计数 epoch、有效标志、两轴角度和 CRC-16/CCITT-FALSE。基座只转发校验通过的 H1，不转发任意 UDP 文本命令。
- epoch 确保最新包合并时也能检测到切换动作。重复的云台包不会不断取消网页自动扫描；网页软件停止也不会被同一模式的下一包立即解除。
- CRC 只检测传输错误，不是身份认证；默认热点密码不是产品级安全机制。仅在自己的隔离测试网络使用。
- 四轮输出限幅为 350/1000，占空比逐渐变化；换方向先降到零，再等待至少 100ms。
- 手持数据超过 250ms 未更新时撤销驱动；不是用“主循环重复读同一包”续期。
- TIM7 每 1ms 检查输入时效和主循环，主循环超过 120ms 未服务会保护停车；数值是软件设计阈值，未在实物上测定停车距离。
- 硬件异常处理也调用 PWM 归零。中断全部失效、调试暂停、供电故障等情况下，软件不能保证停车；必须有独立硬件断电措施。
- PWM 归零在该板对应制动，**不等于车辆机械瞬间静止**。惯性、负载、地面和电池回灌风险仍需评估。
- 没有把超声波读数直接当作全方向自动刹车传感器：云台可能朝别处，侧后方也没有覆盖。现有距离声光提醒保留。
