# 扫描网页与控制模式

## 使用方式

1. 烧录 `ESP01S_Base_UDP/ESP01S_Base_UDP.ino` 到基座 ESP-01S。
2. 烧录当前 `project.uvprojx` 到 STM32。
3. 手机连接基座热点 `GimbalCtrl`，密码 `<LOCAL_WIFI_PASSWORD>`。
4. 浏览器打开 `http://192.168.4.1`。

原有两个桌面网页仍保留，继续使用 `/api/telemetry`：

- `gimbal-radar-standalone.html`
- `gimbal-3d-scan.html`

## 独立控制网页

基座 ESP 的首页提供：

- `Horizontal scan`：Roll 在 `-60` 到 `+60` 度往返，Pitch 回到 0 度。
- `Vertical scan`：Pitch 在 `-30` 到 `+30` 度往返，Roll 回到 0 度。
- `Full scan`：Roll 往返一行，到边界后 Pitch 每次改变 10 度，范围 `-30` 到 `+30` 度。
- `Stop / Center`：停止扫描并回到中心。
- `Handheld mode`：恢复手腕端 MPU6050 控制。

扫描命令由基座 ESP 通过 USART1 发给 STM32：

```text
M,HORIZONTAL
M,VERTICAL
M,ALL
M,STOP
M,HANDHELD
```

扫描时手持端 UDP 姿态仍可接收，但不会覆盖扫描舵机目标；选择 `Handheld mode` 后恢复手腕控制。

## 接线保持不变

基座 ESP 与 STM32：

```text
ESP TX -> STM32 PA10 (USART1_RX)
ESP RX <- STM32 PA9  (USART1_TX)
GND 共地
```

原有 HC-SR04、舵机、TFT 和手持 ESP 接线不变。
