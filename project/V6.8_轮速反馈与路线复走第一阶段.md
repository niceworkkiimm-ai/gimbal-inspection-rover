## 现在做到了什么

- STM32 读取原有四轮编码器，计算各轮实际转速；编码器接线、计数方式不变。
- 增加前馈 + PI 轮速控制器，但默认关闭，只监测。原来的体感遥控仍使用原 PWM 控制，最大占空比仍为 30%。
- 基座 ESP 把轮速诊断通过现有 Wi-Fi 链路送到网页。
- 2D、3D 页面增加“四轮速度反馈”：实测转速、目标转速、PWM 命令、状态和最近约 24 秒的曲线，可导出 CSV。
- 原有气体、超声波、雷达视图、行驶轨迹、本地巡检档案保留；距离刻度和点数不改。

## 烧录后的第一步：只观察，不开启新闭环

1. 确保车架固定、四轮离地，有办法立即直接切断电机电源。
2. 给基座和手持端正常上电，电脑连接基座热点，打开新版网页。
3. 找到“四轮速度反馈”。正常应显示“监测模式 · 未接管电机”。目标转速显示横线是正常的，因为此时仍是原 PWM 遥控。
4. 切换小车模式，按照原来的操作回中，再轻轻向前倾几秒。
5. 在**轮子确实按小车前进方向转动**时，观察四轮实测转速是否都是正数。后退时应都为负数。停车后短暂的速度窗口消退是正常的。
6. 把前进时四轮数值截图发来，或者点“导出轮速诊断”。有某轮为负、一直为零或明显跳变，先检查方向标定、脉冲和接线，不要开启闭环。

目前主控暂按之前前进测试的推断使用方向 `[+1, -1, +1, -1]`，这不是新的实物确认。若你后来改过网页里的四轮方向，主控不会跟着自动修改；面板会提示网页与主控的标定差异。

## 参数和闭环工作方式

参数集中在 `Hardware/WheelSpeedConfig.h`：

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `WHEEL_SPEED_ENABLE` | `0` | 默认仅监测，未接管电机 |
| `WHEEL_SPEED_CPR` | `374` | 11 脉冲 × 34 减速比，A 相上升沿 1 倍计数；仍需手动转一整圈验证 |
| `WHEEL_ENCODER_SIGNS` | `{1,-1,1,-1}` | 各轮编码器方向修正，独立于电机 DIR 极性 |
| `WHEEL_SPEED_MAX_RPM` | `30` | 可选闭环的请求转速上限，不保证实际达到，也不是当前开环的转速上限 |
| `WHEEL_SPEED_PERIOD_MS` | `40` | 两次速度采样最小间隔；使用实际间隔计算，不假定每次刚好 40 ms |
| `WHEEL_SPEED_WINDOW` | `3` | 最多三个样本的时间加权速度窗口；正常约 120 ms |
| `WHEEL_SPEED_FF/KP/KI` | `4.0 / 1.5 / 1.0` | 初始试验参数，不是实车调好的参数 |

开启闭环前先核对四轮方向、每圈计数、可直接断电的措施，再安排单轮/四轮架空低速测试。**这一版先保持 `WHEEL_SPEED_ENABLE=0`。** 后面把它设为 1 也只是轮速闭环，不会变成自动路线复走。

可选闭环每轮按目标与实测转速调节 PWM，保留 30% 输出限制、缓启动和换向停顿。积分有正负限幅与抗饱和，低速反向反馈也进行检查。停车、失联和输入无效会清零控制输出与积分。

闭环状态下，采样间隔超过 120 ms、异常计数跳变、持续反向反馈或施加一定输出后持续无脉冲，会停止四轮并保持故障，不自动退回开环。“无脉冲”可能是传感器断线或轮子不转，软件不能断言一定是堵转。排查原因后切出小车模式再重新进入。

## 不变的功能与安全边界

- 手持前后/左右方向、回中规则、短暂异常恢复和 250 ms 输入失联停车保持原样。
- 轮速采样和控制计算在主循环，编码器中断只计数，不在中断里做浮点控制或串口打印。
- TIM7 原有停车检查保留；计算结束、提交 PWM 前再次检查停车状态，避免覆盖刚发生的中断停车。
- 网页仅显示，不直接控制电机。CRC 用于检查传输损坏，不是身份认证。
- 软件停车不能代替直接切断电机电源；PWM 百分比不是电流测量，也不能证明电机已执行命令。
- 轮速闭环不能消除麦轮打滑，也不是 SLAM 或绝对定位。
- `System/Delay.c` 仅补了文件末尾换行来消除原编译警告，原有字节、编码和延时逻辑保留。

## 后续路线复走的顺序

1. 核对轮速方向与每圈计数，在可立即断电条件下低速调好闭环。
2. 在 STM32 增加本地位姿估算和短距离路径跟踪；不依赖网页实时下发每个电机 PWM。
3. 网页导入已保存巡检路线，检查坐标、单位、断点和起点，先预览，不能导入就自动启动。
4. 车放回原起点并对齐原朝向，人工确认后执行短距离低速复走。遇障停车、人工接管、通信超时停车，不先做自动绕障。

已保存路线主要是轮式里程计估算。重启后的坐标清零不等于找回原来的物理位置；长距离或打滑情况下，要加入额外定位/校正才能提高重复精度。现有单个可转动超声波也不能覆盖车身四周、后方和地面落差。
