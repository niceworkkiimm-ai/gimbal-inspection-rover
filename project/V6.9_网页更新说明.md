# V6.9.1 网页更新（2026-09-11）

范围已纠正：保留路线保存与查看，简化操作；只删除扫描点图的记录、存档、编号和回看。没有恢复繁琐的巡检档案面板。

“巡检行驶轨迹”中只有两个路线文件入口：

- **保存路线**：保存点击时的路线到 JSON 文件，包含路程、朝向、标定和分段信息，不含扫描点。
- **打开路线**：选择以前保存的路线 JSON，离线也能看；旧“巡检_...”JSON 也能打开其中的路线，忽略扫描点。

打开旧路线后显示“返回实时”按钮，回到正在接收的路线。查看旧路线不会混入实时数据，不会改变当前轮向标定，不会发送驾驶命令。

保留实时 2D/3D 扫描、模型与点云、气体数据、实时路线、原有“导出轨迹”、标定和 RPM 面板。距离范围、显示比例、点数、轮向、驱动和闭环开关不变。

第一次点“保存路线”，选择桌面的 `路径保存数据库` 文件夹并允许写入。同一次打开网页后再次保存，不必重复选择；重新打开网页时可能需要再次授权。每次保存新文件，不覆盖之前的路线。浏览器不支持选择文件夹时，使用另存为或下载，请在下载记录中确认文件并放入指定文件夹。

桌面“路径保存数据库”里的已有资料没有修改或删除。旧版复杂档案实现仍只在 D 盘缓存备份中，不在当前网页加载。

直接刷新本文件夹的 `gimbal-radar-standalone.html` 或 `gimbal-3d-scan.html` 即可；若仍见旧面板，关闭页面后重新打开。STM32、基座 ESP、手持端都不用重新烧录，所有接线不变。主函数开头只同步更新项目版本说明，固件仍为 V6.8。

你的 RPM 前进变化、减速归零的反馈已收到；本次不调整已经正常的轮速部分，不启用新的闭环或自动行驶。后续扫描点图回看另行一步一步设计。
