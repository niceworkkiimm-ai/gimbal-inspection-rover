## 第一次使用

1. 打开网页，在新增的“巡检档案”区域点击“选择保存文件夹”。
2. 在弹出的浏览器窗口中选中 `C:\Users\YOUR_USER\Desktop\路径保存数据库`，同意读取/写入权限。网页只能知道所选文件夹的名字，选目录时请自己确认完整路径。
3. 连接基座，检查下面的“轨迹标定与轮子方向”。需要收到新编码器数据且完成标定，才能把本站位置标到路线上。不会自动改变你之前保存的四轮方向。

浏览器禁止网页悄悄写入任意电脑目录，因此这一步授权不能省略。若浏览器不支持选择文件夹，会使用保存文件对话框或下载；请自行选择/移入指定目录。仅触发下载时，网页不会把它当作已验证的存盘成功。

## 实际记录

1. 手动把车开到需要检查的位置，停稳；如要新的起点，先点击“新建巡检 / 重设起点”。网页不会发出停车指令。
2. 输入巡检名称、巡检点名称和可选备注。
3. 点击“开始本站记录”，确认停车，然后使用原有手控或自动扫描功能转动云台。
4. 本站记录独立于上方实时点云：不受2D实时点5秒清理、3D清屏或实时暂停影响。不移动车体；如果估算移动超过3cm或旋转超过2°，会提示点图可能混合不同位置。
5. 扫描结束，点击“完成本站并存档”。已授权文件夹时，会把该巡检的路线、全部已完成巡检点一起写成新的 JSON 文件。路线出现对应的金色编号。
6. 前往下一处，重复开始/完成。本次最多100个巡检点；每站最多800个角度点，最长记录10分钟。2°角度格合并重复方向，同方向使用最近5次有效距离的中值，不会定时删除本站已采集点。
7. 整次巡检走完，再点击“保存整次巡检到本地”，把最后一站之后的路线也存进去。保存的是点击时的数据快照，后续行驶不会自动加入已经写好的文件。

每次存盘生成带时间和编号的新文件，不自动覆盖已有档案。失败或取消存盘时，巡检点仍留在当前网页，关闭前请重新保存。未存盘时关闭网页会尝试提示，但浏览器崩溃/强制退出无法保护内存记录，重要数据应及时存盘。

## 重启后回看

1. 小车不必开机，打开同一个2D或3D网页。
2. 点击“读取文件夹档案”；浏览器如要求，重新允许读取。也可以直接点击“打开本地档案文件”，选择之前保存的 JSON。
3. 历史路线会恢复，点击路线金色编号或巡检点卡片，可以看当时的俯视图、高度图以及气体快照。在3D页面还可以旋转查看三维点图。
4. 两页使用相同文件格式：2D保存的档案可以在3D页面打开，反之亦然。原始角度和距离存在文件内，回看保持各页既有方向和近距放大规则。
5. “返回实时巡检”恢复当前路线。打开历史档案不会把新车轮数据接到旧路线终点，也不会发送电机指令。

基座/主控会话变化、手动重设起点或更改标定时，旧巡检保留在列表中，新巡检从新起点开始。未存盘的旧巡检要单独选择并保存。重启并不意味着小车已定位回原来的世界坐标。

## 文件里面有什么

版本号、巡检名称、时间、轮子标定、相对起点、路线点、每站估算位置/朝向、测量原始角度/距离、气体的单位/有效性/状态、备注和异常提示。不是截图，不保存 Three.js 模型对象，也不保存 Wi-Fi 密码。

保持现有150cm显示范围和近距放大比例；无回波、超范围、重复序号、过期帧不会伪造成障碍物点。本站至少要有一个范围内有效点才可完成点图存档。历史气体数据只代表采集当时的有效读数；离线数据是未知，不是0。

这是“编码器估算路线 + 各停车点的局部扫描档案”，不是精确地下定位、地图拼接或 SLAM；麦轮打滑会产生误差。静止检查也是编码器估算，不能检测所有打滑。三维/高度显示不等于精密测绘，高度为相对超声波水平位置。

导入单文件上限20MB，一次浏览最多20份巡检；目录列表最多300个文件。文件内容会校验，不支持的版本或格式会报错，不会覆盖当前已打开的档案。
