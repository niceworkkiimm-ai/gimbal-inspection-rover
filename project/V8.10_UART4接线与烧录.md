# V8.10：基座通信改用UART4

日期：2026-09-19。只需重烧STM32，基座ESP V4.9、手持V1.5、摄像头V1.2、网页V8.9不变。

## 断电后换线

| 基座ESP-01S | STM32/电源 |
| --- | --- |
| TX | PC11，UART4_RX |
| RX | PC10，UART4_TX |
| GND | STM32 GND，共地 |
| VCC | 稳定3.3V，不变 |
| EN/CH_PD | 稳定3.3V，不变 |
| GPIO0 | 正常运行不接GND，不变 |

撤掉原来连接PA9/PA10的两根ESP信号线，不要新旧接口同时连接。
PA9/PA10的板载串口跳线帽不再参与ESP通信，可以保持原样。
PC10/PC11不能同时连接其他串口设备或被SD卡/SDIO占用。
其他模块包括TFT显示屏、气体USART2、电机、编码器、手持端接线完全不变。

## 烧录

打开当前目录Gimbal_STLink.uvprojx，目标选Gimbal STLink，先Rebuild，再Download到STM32。
不要直接使用旧Objects目录中未重新编译的文件。
也可使用已编译的固件/V8.10/Gimbal_STLink_V8.10.hex下载。
不需要重烧任何ESP，也不需要更新网页；ESP源文件仅补充当前接线注释。

## 改动和验证

- GPIOC PC10/PC11、AF8、APB1 UART4时钟、UART4_IRQn与UART4_IRQHandler完整迁移。
- 标准库根据PCLK1计算115200波特率；8N1、数据格式、缓存与超时逻辑不变。
- USART1不再由本程序初始化；USART2气体通信不变。
- 主函数开头更新版本号和完整接线；屏幕版本标识改为V8.10。
- Keil重编译：0错误、0警告；链接结果确认UART4中断绑定到实际通信处理函数。
- 主机模拟测试通过：收发解析、CRC/序号拒绝、通信故障、手动控制、回中和失联停车。
- 对比检查确认协议、控制参数、显示屏和其他模块代码未变；这不是实机通信测试。
