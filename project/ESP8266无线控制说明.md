# ESP8266 无线控制

工程已经使用 STM32F407 的 USART2 与 ESP8266 通信。ESP8266 运行 `ESP8266_Firmware/wifi_bridge/wifi_bridge.ino` 后会建立一个 Wi-Fi 热点和 TCP 服务，手机或电脑连入后可直接控制云台并接收状态。

## 接线

| STM32F407ZG | ESP8266 | 说明 |
| --- | --- | --- |
| PA2 (USART2_TX) | RXD | STM32 发送至 ESP8266 |
| PA3 (USART2_RX) | TXD | STM32 接收 ESP8266 数据 |
| GND | GND | 必须共地 |
| 独立 3.3 V | VCC、EN/CH_PD | 供电需稳定，峰值电流至少 500 mA |

ESP8266 的 GPIO0 正常运行时接高电平，不能接 5 V。STM32F407 的 PA2/PA3 均为 3.3 V 电平，能直接相连。

## 烧录 ESP8266

使用 Arduino IDE 安装 ESP8266 开发板支持，打开 `ESP8266_Firmware/wifi_bridge/wifi_bridge.ino`，选择对应 ESP8266 板型并上传。ESP-01 烧录时将 GPIO0 接地后复位；上传结束后断开 GPIO0 与 GND 的连接并重启模块。

默认热点和 TCP 服务如下：

| 项目 | 默认值 |
| --- | --- |
| Wi-Fi 名称 | `Gimbal-8266` |
| Wi-Fi 密码 | `<LOCAL_WIFI_PASSWORD>` |
| TCP 地址 | `192.168.4.1:8080` |
| STM32 串口速率 | `115200, 8N1` |

可在 `.ino` 开头修改热点名、密码与端口。

## 控制协议

在手机 TCP 调试助手或电脑 TCP 客户端连接 `192.168.4.1:8080`，按以下格式发送，以换行结尾：

```text
CTRL,30,-20\n
```

其中第一个值控制 Roll 舵机，第二个值控制 Pitch 舵机，取值范围均为 `-90` 至 `90` 度。接收到一条合法 `CTRL` 后，系统自动切到无线控制。

```text
MODE,IMU\n
MODE,WIFI\n
```

`MODE,IMU` 恢复原有 MPU6050 体感控制；`MODE,WIFI` 保持当前无线目标角度。云台会约每 0.5 秒回传一次下列数据：

```text
STATUS,roll,pitch,distance\r\n
```

三个字段依次是 MPU6050 当前 Roll、Pitch 和 HC-SR04 距离（厘米）。

## STM32 改动

`Hardware/ESP8266.c` 负责 USART2、中断接收、命令校验和状态发送；`User/stm32f4xx_it.c` 增加 USART2 中断；`User/main.c` 在无线模式时改用命令角度控制舵机。`project.uvprojx` 已经加入新源文件，打开 Keil 后可直接重新编译。
