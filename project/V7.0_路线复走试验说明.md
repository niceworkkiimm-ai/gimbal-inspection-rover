# V7.0 路线复走试验（2026-09-12）

这是第一版低速、有人看护的路线重复行驶，不是矿井无人驾驶成品，不是SLAM。

## 更新哪些设备

- STM32：打开本目录的 `Gimbal_STLink.uvprojx`，重新编译并烧录 V7.0。
- 基座 ESP-01S：烧录 `ESP01S_Base_UDP/ESP01S_Base_UDP.ino`，版本 V4.6。
- 手持 NodeMCU：不需要烧录，MPU、按钮、OLED和接线不变。
- 网页：仍打开本目录的 `gimbal-radar-standalone.html` 或 `gimbal-3d-scan.html`。不要只复制HTML，保留旁边的JS和原有Three.js等依赖。
- 本次没有替你烧录，也没有向真实车辆发送驾驶命令。编译与模拟通过不等于实车验证完成。

## 新界面

保留“保存路线”“打开路线”“返回实时”，只加“按路线行驶”“停止”。原先删除的扫描点档案/回看不恢复。

打开文件只显示历史路线，不会启动。点击“按路线行驶”并确认后，网页先停车，逐点上传，等待STM32校验、确认，再开始。运行时黄色箭头显示STM32估算的位置。右边原有历史路线统计仍是保存文件的信息，不是自动行驶的实时速度；实时RPM看原有轮速面板。

浏览器网页须保持前台、电脑不休眠，手持端开机并保持小车模式和水平。不要同时在2D和3D页面发起任务。

## 第一次测试顺序

1. 保留电机电源切断开关，先架空四轮并固定车架，确保转动部件不会碰到人或线。
2. 更新STM32和基座后，先确认旧的手控前进、转向、四轮计数和RPM仍正常。
3. 在平整空地重新录1至2米缓慢前进的直线：先在网页点“以当前位置重新开始”，保持页面前台，停车后保存。先不录复杂转弯。
4. 再次架空车轮，用这个文件检查自动模式轮向；前方放一个距离约1米、回波稳定的挡板供测距。点开始，检查低速转动。分别测试网页“停止”、倾斜手持、切换按钮、断网页连接、前方移入近物，确认PWM归零，实际车轮停止。轮子惯性不等于软件未停车。
5. 架空和异常停车均确认后，再回到平整空地，把车放回原路线起点，车头对齐原方向，打开路线、确认开始。人员在旁边随时断电。
6. 先测短直线终点偏差，再测一个缓慢转弯；每次停止后必须重新对准起点再开始，不能从任意位置接着走。

## 限制与停车条件

- 第一版只接收前进、转向路线，不支持倒车、横移、自动绕障、断点续走。
- 总路线0.1至10米，控制点最多256个；初次建议1至2米。路点简化仅允许约1cm位置误差、0.08弧度角度误差，不跨数据缺口。
- 车轮直径97mm、左右轮距202mm、前后轴距210mm、CPR374、原始计数轮向 `+1,-1,+1,-1` 必须与文件一致。标定修改不会自动写入STM32。
- 自动模式启用独立的初始轮速闭环，前进目标最高约0.07m/s，单轮目标最高18RPM，PWM不超过30%。这是指令上限，不是实测速度/精度承诺；手控PWM及方向不变。
- 自动模式探头固定车头正前方并等待稳定。距离不足30cm停车，无回波、测距超时或无效也停车。若4米内没有有效反射物，也可能停止，不能把“无回波”当作前方安全。
- 单个高处探头不能覆盖车体侧面、盲区、低矮物、台阶或坑洞。只在平整空旷场地验证，不能依靠它保障真实矿井行驶安全。
- 手持端失联超过250ms、网页有效续约超过600ms、主循环服务间隔超过120ms会切断PWM；编码器异常、严重偏离、8秒无进展或总运行超过180秒也会停止。实际车轮停车距离还取决于惯性和地面，必须实测。
- 倾斜手持端会停车但不自动接管驾驶；切换手持按钮可退出自动控制，切回小车后仍需要原有的回中确认。异常解除不会自行恢复旧路线。
- 断电重启后不自动恢复。ESP不代替网页发送续约，网页卡住不会让旧命令一直保持。

## 为什么连续走也有数据缺口

车在连续运动和网页连续收到有效数据是两回事。现有基座保留最近16帧编码器数据，约1.28秒；网页延迟超过这个窗口、Wi-Fi掉线、设备重启、记录会话变化等，都可能使中间采样丢失。累计轮计数能给出增量，但不能还原缺失期间先转弯还是先前进。

旧文件只保存结果，没有逐次通信日志，无法凭文件确定每一处缺口的确切原因；“会话切换”也不能单独证明某块板真的重启。本次不删除、不伪造或自动补齐旧文件里的缺口。

目前检查到的已保存路线含缺口及会话切换，仍可打开查看，但不能用于整条自动复走。请按上面的步骤录一条新的连续短路线。若新录仍有缺口，需要继续记录主控运行时间和网络接收日志，定位断在哪里，不能关掉检查强行行驶。

## 接线与供电

无新增引脚。主函数开头已更新V7.0并保留下方完整接线表。

- 基座ESP TX -> STM32 PA10；RX -> PA9；VCC/EN稳定3.3V；GND共地。
- 编码器1左前：A PE2，B PF8；2右前：A PE3，B PF11；3左后：A PF6，B PD6；4右后：A PF7，B PD7。
- PWM：PC6、PC7、PE5、PE6；DIR：PC4、PC5、PB12、PB13，依次对应1至4轮。
- 手持D1/D2 I2C、D5按钮及现有电源不变。PD3仍不接，没有增加虚构的急停输入。
- 用户已确认存在电机电源切断开关。必须使用，软件停车不能取代物理断电。
