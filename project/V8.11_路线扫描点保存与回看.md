# V8.11 路线扫描点保存与回看

本次仅更新 2D/3D 网页。车辆路线上的红点保存停车位置对应的当前扫描点图，可点击回看，并随路线 JSON 一起保存和重新打开。

## 使用步骤

1. 在线连接车辆，停车并扫描到所需点图。保存前需有新鲜的路线和扫描数据，且原生路线记录同步完成。
2. 点击路线面板的“保存当前扫描点”，在当前路线位置生成红点。
3. 点击红点回看对应点图；3D 快照可旋转查看，两个页面均可打开。关闭回看窗口后继续查看现场。
4. 点击“保存路线”，将包含路线和扫描快照的 JSON 写入所选目录，或按浏览器提示下载。
5. 使用“打开路线”载入文件，恢复路线红点和点图，再点击红点回看。

2D、3D 页面均支持上述功能。打开历史文件后，点击“返回实时”可回到本次在线路线。

快照是保存时网页当前显示的扫描缓存，不是对“一次完整扫描已完成”的自动判定；保存前请确认画面就是需要保留的内容。3D 扫描会累积点云，到新点位后可先用现有“清空点云”再扫描；这不会删除已保存的路线红点。新红点先保留在浏览器内，关闭网页前请点击“保存路线”写入文件。

## 文件和范围

- 新路线 JSON 使用 `version: 2`，包含扫描快照；不保证旧版网页能读取新格式。
- 旧 `version: 1` 路线仍可打开，原文件没有的扫描快照不会被补造。
- 每条路线最多保存 100 个扫描点位，每点最多 800 个扫描采样；路线 JSON 文件上限为 20 MB。
- CSV 仍只导出路线，不包含扫描快照。
- 红点位置来自编码器路线估算，不是全局建图定位。该功能不包含气体或图传存档，也不恢复按保存路线自动行驶。
